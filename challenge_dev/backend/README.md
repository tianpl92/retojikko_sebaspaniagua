# Public Calls Portal — Backend

Go backend service for the Public Calls Portal application. Provides RESTful JSON endpoints for browsing, filtering, and saving public calls for proposals from datos.gov.co.

## Env vars required

| Variable     | Description                        |
|--------------|------------------------------------|
| `DB_USER`    | PostgreSQL database user           |
| `DB_PASSWORD`| PostgreSQL database user password  |

Create a `.env` file in this directory with the variables above before running the application.
