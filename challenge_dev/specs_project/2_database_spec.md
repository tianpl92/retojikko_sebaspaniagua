### 3) Association table between a public call and a user

This table links one public call for proposals to one registered user.

**Required fields and rules:**
- `id` must be a **UUID primary key** and automatically generated by default.
- `public_call_id` must reference the UUID primary key of the public calls table.
- `user_id` must reference the alphanumeric primary key of the `users` table.
- `association_date` must be a timestamp automatically populated with the current date/time on insertion.
- **All fields must be `NOT NULL`.**

**Suggested technical specification to describe in the final instructions:**
- `id`: UUID, primary key, default random UUID.
- `public_call_id`: UUID, required, foreign key.
- `user_id`: alphanumeric/textual, required, foreign key.
- `association_date`: timestamp, required, default current timestamp.
